# Sistema de Gestion Academica DiplomadosOnine (SGA-DO)

## Detalles del Proyecto
El SGA-DO es un Motor Core desarrollado para el departamento de control de estudio de DiplomadosOnline.com. Su objetivo es reemplazar el manejo actual del archivo en Excel mediante un sistema estructurado y operado por consola, el cual se encargara de automatizar los cálculos de las certificaciones y garantizar la persistencia segura de los datos a través de archivos de texto plano (`.txt`).

## Arquitectura Técnica (Programacion Orientada a Objetos)
El codigo fuente se implementara de manera independiente en tres lenguajes de programacion:
* **Python**
* **Java**
* **C++**
